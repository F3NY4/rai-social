# Отчёт о проверке

Среда проверки — Linux, Node.js 24.22.1 и браузеры из Playwright. Автоматические тесты используют отдельное хранилище. Настоящая языковая модель проверяется отдельно от модульного `ModelProvider`-двойника.

| Область | Что проверено |
|---|---|
| Типы | `npm run check` завершился без ошибок и предупреждений |
| Модульные тесты | 11 тестов Vitest. Изоляция миров, записи и реакции, членство в чатах, отношения, память, JSON/V2, круговой импорт, миграция, валидация модельных действий, приоритет и отмена, черновик альтернативной реплики |
| Статика | Production-сборка через adapter-static. Сборка с `BASE_PATH=/rai-social` открыла прямую ссылку `/rai-social/#messages` и сохранила её при офлайн-перезагрузке |
| Мобильный WebKit | 3 теста Playwright WebKit с профилем iPhone 13. Проверены создание публикации, реакция, комментарий и восстановление без сети, создание вселенной и персонажа, сохранение личной переписки, изоляция демонстрационных данных, смена языка и темы, скачивание резервной копии |
| Реальная модель | В Chromium и Linux WebKit скачан из Hugging Face Qwen2.5-0.5B-Instruct Q4_K_M. Приложение подтвердило SHA-256. После отключения сети браузеры сгенерировали и записали комментарии от персонажа к новому посту |
| Физический iPhone 13 | Доступа к устройству не было. Производительность, устойчивость и режим PWA в Safari iOS 27 остаются непроверенными |

В прогонах Chromium модель сформировала реплики на русском языке. В одном из прогонов она повторила входной вопрос вместо содержательного ответа. Результат на Linux WebKit также содержал русский комментарий и технически прошёл путь до сохранения в IndexedDB. Связность персонажа, естественность реплик и длительная работа на A15 требуют отдельной оценки. WebGPU, SmolLM2 и Qwen 1.5B в этих экспериментах не запускались.

Лимит хранилища воспроизвёлся в непостоянном контексте Chromium. При потоковой записи в один OPFS-файл и использовании постоянного контекста скачивание и офлайн-комментарий прошли. Лимит конкретной среды и политики приватного режима могут отличаться.

## Как повторить

```sh
npm ci
npm run check
npm test
npm run build
npx playwright install --with-deps webkit chromium
npm run e2e
```

Для реальной модели запустите `npm run preview` в одном терминале и `npm run test:model` в другом. Для Linux WebKit используйте `RAI_BROWSER=webkit npm run test:model`. Каждый запуск создаёт временный профиль и скачивает около 398 MB, поэтому тест с моделью запускается отдельно от обычного CI. Отчёт о работе iPhone следует заполнять по списку в [IOS_COMPATIBILITY.md](IOS_COMPATIBILITY.md).
